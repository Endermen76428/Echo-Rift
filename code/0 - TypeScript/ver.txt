Echo Rift v0.1.1 Alpha
> Features:
Blocks:
  > Marble:
    - Added crafts to Slabs, Vertical Slabs and Stairs in all marble variations.
    - Memory Fragment Ores had the loot table changed:
      - Now it drop Memory Fragments instead of the Complete Memory;
      - No Enchant: 1 - 3 Fragments;
      - Fortune I: 1 - 5 Fragments;
      - Fortune II: 1 - 7 Fragments;
      - Fortune III: 1 - 9 Fragments.
    - Marble Slabs can now be stacked.
    - Vertical Marble Slabs can now be stacked.
Items:
  > Guide Book:
    - When it's your first time using the addon you will receive a Guide Book.
    - You can craft a Guide Book with a Book and any Memory.
  > Memories:
    - Memory Fragments Forgotten Kingdom were renamed to "Memory of Forgotten Kingdom", to avoid confusion with the new items.
    - Change the Memory item texture.
    - Added the Memory Fragment of Forgotten Kingdom item as an previous veriosn of the Memory of Forgotten Kingdom item.
    - Using nine of any memory fragment you can create a Complete Memory.

> Bug Fix:
Blocks:
  > Voxel Shapes:
    - Blocks of Marble and their variations had their Voxel Shape changed to the blocks of:
      - Slabs;
      - Vertical Slabs;
      - Stairs.
    - Red Marble Slabs no longer disappear when placed one on top of the other.



Echo Rift v0.1.0 Alpha
> Features
Biome:
  > Marble Caves:
  - Marble Caves is a new biome which can be found around the biomes:
    - Plains;
    - Sunflower Plains;
    - Forest;
    - Flower Forest;
    - Birch Forest.
  - The biome has all underground replaced by Marble Blocks:
    - Marble Block;
    - Red Marble block;
    - Black Marble Block.
  - You can find the blocks of Marble with a Mempory Fragment anywhere in the biome, in its all-marble version.
  - Forgotten Kingdom Portal is a new structure found on Marble Cave Biome.
